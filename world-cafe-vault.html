    Import, Connections & Data

    CSV import

    Pick one or more CSV exports of your Sheet tabs: Playlists, AltRadio, Show_Archives, Saved_Playlists. Each file's format is detected automatically and you see a preview before anything is saved. Tracks already in the library (same artist + song + show date) are skipped, and Spotify / YouTube URLs are stored exactly as they appear in the file.

    Spotify connection

    Paste the Client ID from your Spotify developer app once; it is saved in this browser only. Sign-in uses PKCE (no client secret), asks only for permission to create private playlists, and lasts about an hour in this tab.

    Redirect URI for this page:

    YouTube API key

    Paste the API key from your Google Cloud project once. It is used only to search YouTube (no sign-in), is saved in this browser only, and is never included in backups or written into the app file.

    YouTube account (playlist export)

    Paste the OAuth Client ID from your Google Cloud project once; it is not a secret and is saved in this browser. Sign-in uses Google's own pop-up (no client secret), asks to manage your YouTube account so the app can create private playlists, and lasts about an hour in this tab. Works only while Google Advanced Protection is off; because the app is in Testing mode, Google asks you to re-approve about once a week.

    Live feeds

    World Cafe daily, XPN2 hourly and Out of the Box imports arrive in a later phase.

    Backup & restore

    Your library lives in this browser only; your phone and computer each keep their own copy. Download a backup to save it, and restore it on another device.
