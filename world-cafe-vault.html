            Imports, Connections, etc.

            World Cafe daily shows, XPN2, AltRadio and Out of the Box can be imported here. The Sheet's CSV import still works too.

            Imports

            World Cafe Daily shows from XPN

            Adds World Cafe shows from the playlists XPN posts for each weekday show (back to 2019), in broadcast order, with live-session tracks marked. Shows already in your library are recognised by their songs, even when your Sheet has them a day apart, and are skipped; nothing already in your library is changed. You see the tracks before anything is saved.

            CSV import

            Pick one or more CSV exports of your Sheet tabs: Playlists, AltRadio, Show_Archives, Saved_Playlists. Each file's format is detected automatically and you see a preview before anything is saved. Tracks already in the library (same artist + song + show date) are skipped, and Spotify / YouTube URLs are stored exactly as they appear in the file.

            Out of the Box Import from the WHRO archive

            Adds Out of the Box playlists from WHRO's public archive (Mon–Thu 7–9 pm, Sat 1–5 pm ET, since 2019). Shows already in your library are skipped, and nothing already in your library is changed. You see a preview before anything is saved.

            Hourly playlists XPN2

            Adds XPN2 playlists one hour at a time from XPN's public playlist page (US Eastern times, back to 2019). Hours already in your library are skipped, the hour still airing is left out, and nothing already in your library is changed. You see a preview before anything is saved.

            AltRadio needs the relay set up on this device (AI relay, above). XPN2 works without it.
            Connections

            Spotify connection

            Paste the Client ID from your Spotify developer app once; it is saved in this browser only. Sign-in uses PKCE (no client secret), asks only for permission to create private playlists, and lasts about an hour in this tab.

            Redirect URI for this page:

            YouTube API key

            Paste the API key from your Google Cloud project once. It is used only to search YouTube (no sign-in), is saved in this browser only, and is never included in backups or written into the app file.

            YouTube account (playlist export)

            Paste the OAuth Client ID from your Google Cloud project once; it is not a secret and is saved in this browser. Sign-in uses Google's own pop-up (no client secret), asks to manage your YouTube account so the app can create private playlists, and lasts about an hour in this tab. Works only while Google Advanced Protection is off; because the app is in Testing mode, Google asks you to re-approve about once a week.

            Sync between devices

            Keeps your library, playlists and selection the same on your computer and phone, through your own Cloudflare Worker (it uses the AI relay address and token below, so set those up first on each device). The YouTube API key, the relay token, the Worker address and all sign-ins stay on each device and are never synced. The last 5 synced copies are kept, so a change can be undone.

            AI relay (playlist builder)

            The AI Playlist Builder talks to your own Cloudflare Worker, which holds the Ollama key. Paste the Worker address and the app token once. Both are saved in this browser only; the token is never included in backups or written into the app file.

            Backup & restore

            Backup & restore

            Your library lives in this browser only; your phone and computer each keep their own copy. Download a backup to save it, and restore it on another device.
